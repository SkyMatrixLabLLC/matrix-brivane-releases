# Data, privacy and disclosure

**Your data is stored on this computer, and only on this computer, unless you connect it to a cloud service or a server.**

_Last updated November 2026. This is the same text the app shows in Settings → Data, privacy and disclosure._

## Where your data lives

Everything you enter in Matrix Brivane (customers, invoices, payments, schedule, finance entries, work logs, settings and backups) is stored in files on this computer.

Sky Matrix Lab LLC does not receive, collect, host or have access to your data. There is no account and no Matrix Brivane server.

Your data only leaves this computer when you choose to connect or use an outside service. It is then handled under that service's own terms and privacy policy:

- **Gmail:** if you link your Gmail, the invoices you send and the mail you read go through Google's servers.
- **Cloud and shared storage:** backups, exports or files you save to a service such as OneDrive, Google Drive or Dropbox, or copy to a USB drive or another computer, are stored there.
- **Updates:** the app contacts GitHub to check for and download new versions. Your data is not sent, but GitHub can see the request (for example your internet address).
- **Payment links (Cash App, Venmo, PayPal and so on):** invoices only contain links that your customers choose to open.

## Backups are your responsibility

Data kept on one computer can be lost if that computer fails, is lost, stolen or reset, if files are deleted, or if the Matrix Brivane data folder is removed. Matrix Brivane makes a daily backup on this same computer, which does not protect you if the computer itself is lost.

Use Settings → Back up now regularly, and keep copies somewhere else, such as a USB drive or a cloud folder.
